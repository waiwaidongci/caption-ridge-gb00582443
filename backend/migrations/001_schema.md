# 001 初始表结构

应用首次启动以 SQLAlchemy 模型创建表与唯一约束。现有数据表只补建缺失表，升级到修改过字段的版本需要显式迁移。

- `users` 账号角色和加盐密码摘要。
- `datasets` 不可变记录批次，以名称和 SHA-256 去重。
- `runs` 记录参数、数据批次、运行租约、分析结果、导出文件及复核决定。
- `schedules` 保存定时计划和下一到期时间。
- `deliveries` 保存站内分发回执，每次运行最多一个回执。
- `simulations` 每次运行一份模拟计划：抽样输入、批次大小、预留分钟、版本号与已发布版本。
- `simulation_batches` 每个样本批次一行，带租约、重试次数和可复现样本；同一批次重试覆盖原行，不重复计入。
- `audit_events` 记录登录、数据入库、运行、模拟批次、预留分钟修订、复核和报表分发动作。
